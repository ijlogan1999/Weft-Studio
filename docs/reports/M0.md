# Milestone 0 report: repository skeleton

## What works

- **Build:** CMake builds the core library, engine library, `weft-cli`, the JUCE app (`Weft Studio`), four fixture VST3 plugins and all tests. Cargo builds the CRDT shim (`weft-crdt`) and the relay (`weft-relay`).
- **CRDT link:** the C++ `weft::doc::Document` wrapper calls Automerge through `weft-crdt`. Tests cover save/load, corrupt input, and two replicas converging after concurrent edits.
- **NullDevice:** a caller-driven audio device for tests and the CLI. Tests cover the prepare/process/release lifecycle, generated input, captured output, odd and variable block sizes (32 to 2,048, plus 441), the audio-thread flag, and deadline-miss counting.
- **Fixture plugins** (spec 06): `TestGain`, `TestLatency`, `TestSynth` and `TestCrashScan`, built from scratch. Tests load the first three through JUCE's VST3 host and check gain (+6 dB), latency (exactly 1,000 samples) and the synth (440 Hz at velocity/127 amplitude). A separate test checks that loading `TestCrashScan` crashes the process.
- **AT-SYS-1 (build-check part):** `tools/third_party.py --check` runs as a test. It fails if `THIRD_PARTY.md` is stale, if a Rust crate lacks a license, or if a fetched C++ dependency or its license files are missing from `third_party/cpp-deps.json`. CMake can only fetch dependencies listed in that file.
- **About box (F-SYS-1 groundwork):** the app shows the version, the AGPL text and the generated third-party notices.
- **Relay:** serves `GET /healthz` on localhost.
- **CI:** GitHub Actions on Ubuntu 24.04 (C++ build and tests, Rust tests, rustfmt, clippy) and Windows (Visual Studio build and tests, app uploaded as an artifact).

## Stubbed or not started

- No WASAPI/ASIO device yet (M2). ASIO needs Steinberg's SDK headers (D-ARCH-4).
- The app window is a placeholder: logo, version, About. The donate button is hidden until a donation URL is set (`-DWEFT_DONATE_URL=...`).
- The relay has no sync protocol yet (M10).
- The AT-RT-1 allocation/lock detector is only the audio-thread flag so far (M2).

## Known issues

- JUCE's own headers emit a few GCC warnings (`-Wclass-memaccess` in the VST3 module info code). They come from the dependency, not Weft code.
- `THIRD_PARTY.md` lists Rust crates for every target platform, so it is a superset of what a given build links.
